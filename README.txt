HARPER & ELLIE MAE CHRISTMAS SITE

This is deliberately a very simple GitHub Pages site.
There are NO external images, CSS files, JavaScript files, libraries, APIs,
fonts, photo services or other third-party software.

Upload index.html and .nojekyll directly into the ROOT of your GitHub repository.

Then:
1. GitHub repository -> Settings
2. Pages
3. Source: Deploy from a branch
4. Branch: main
5. Folder: / (root)
6. Save

Wait a few minutes for GitHub Pages to publish.
